# Диаграмма классов ЛР3

Четыре страницы показаны отдельно от доменов API. Страницы чтения используют обработчики через `api/smart_devices_pages.py`; действия браузера обращаются к `/api` через `static/js/smart_devices.js`. ORM-модели действительно используются обработчиками, отдельного несуществующего слоя сервисов на диаграмме нет.


Полный состав сериализаторов — `api/schemas.py`; полный состав таблиц, ограничения и типы — README. В API возвращаются только `image_key`/`video_key`. HTML-шаблоны формируют ссылки из ключей MinIO; URL в таблице не хранятся.
