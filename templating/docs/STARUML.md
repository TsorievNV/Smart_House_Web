# Компактная диаграмма бэкенда ЛР3

[Открыть SMART_TRAFFIC.mdj](SMART_TRAFFIC.mdj)

Вертикальная схема по образцу: Postman → круглые UML-интерфейсы API → два домена → три модели → три таблицы. API оформлены UMLInterfaceView со stereotypeDisplay = icon (кружок/lollipop).

Показаны только существующие 7 методов smart_devices и 3 метода users. Вход и выход помечены как заглушки. Зависимости доменов от моделей соответствуют коду. Внизу указаны связи таблиц с кратностями.

Для компактности поля моделей и таблиц скрыты на полотне, но сохранены в модели StarUML и доступны в Model Explorer. Подробности фронтенда, сериализаторов и инфраструктуры в этой схеме бэкенда не показаны.

В StarUML раскройте проект и модель, затем дважды нажмите «ЛР3 — Бэкенд SMART TRAFFIC». Проверены ID, ссылки и HTTP-методы. SVG — отдельный предпросмотр, не экспорт из GUI StarUML.
