# Контрольные вопросы

- **Веб-сервис**: программный интерфейс, доступный по сети. В проекте FastAPI принимает HTTP и возвращает JSON; HTML-интерфейс — отдельный потребитель той же бизнес-логики.
- **REST**: архитектурный стиль с ресурсами, единым интерфейсом, отсутствием состояния клиентской сессии в запросах, кешируемостью и разделением клиента/сервера. Сущности здесь — devices/users; ресурс публикации отделён от удаления.
- **RPC**: вызов удалённой операции. REST ориентируется на ресурсы и HTTP-семантику, RPC — на имена вызываемых процедур.
- **HTTP**: запрос содержит метод, адрес, заголовки и необязательное тело; ответ — статус, заголовки, тело. Content-Type описывает представление, Accept — желаемое представление; Authorization используется для учётных данных, но в ЛР3 не реализован.
- **Методы**: GET читает без изменения состояния, POST создаёт или выполняет операцию, PUT задаёт состояние ресурса, PATCH меняет часть данных, DELETE удаляет ресурс с точки зрения клиента. Логическое удаление сохраняет строку в БД. HEAD — заголовки без тела, OPTIONS — возможности взаимодействия.
- **Идемпотентность**: повтор операции имеет тот же итоговый эффект. Повторный DELETE может вернуть 404, а PUT публикации 403, не меняя уже полученный результат в БД. POST лайка с одинаковым value не создаёт дубликат.
- **Версии HTTP**: HTTP/1.0 — ранняя текстовая версия; 1.1 — постоянные соединения и Host; HTTP/2 — бинарные кадры и несколько потоков внутри TCP; HTTP/3 — QUIC поверх UDP.
- **HTTPS**: HTTP с защитой TLS: шифрование, целостность, проверка сервера сертификатом. Локальная демонстрация использует HTTP.
- **OSI ISO**: физический, канальный, сетевой, транспортный, сеансовый, представления, прикладной уровни. IP относится к сетевому, TCP/UDP — транспортному, HTTP — прикладному. Модель OSI концептуальная, стек TCP/IP не повторяет её уровни один к одному.
- **ORM и сериализатор**: ORM связывает классы с таблицами и формирует SQL; Pydantic-модель ограничивает вход и определяет JSON-ответ. Изменение полей ORM после проверки бизнес-правил сохраняется через commit.
- **Singleton ЛР3**: `lru_cache(maxsize=1)` кеширует неизменяемый объект фиксированного пользователя; функция применяется через Depends. Это учебная замена авторизации, а не механизм безопасности для публичного сервиса.
